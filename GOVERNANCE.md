# Governance

Open Agent OS uses **evidence-first, vendor-neutral governance**.

## Principles

1. Maintainers curate scope, taxonomy, evidence quality, and releases.
2. Canonical contract changes require an RFC.
3. Lasting repository implementation decisions should use an ADR.
4. A proposal is not promoted solely because it is popular.
5. Interoperability, security, operability, migration cost, and failure recovery must be considered.
6. Vendor-specific semantics do not become canonical unless the abstraction is justified independently.
7. Conflicting evidence remains visible.
8. Major architectural claims should be independently reviewed before becoming baseline guidance.

## Decision labels

- `OBSERVED`
- `INFERENCE`
- `PROPOSAL`
- `ALTERNATIVE`
- `REJECTED`
- `OPEN QUESTION`
- `V1`
- `FUTURE`
