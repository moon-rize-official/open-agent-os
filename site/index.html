Build agent systems from replaceable parts.

Open Agent OS is a public research and specification project for modular AI/agent operating systems: stable contracts for runtimes, models, tools, memory, knowledge, workflows, security, compute, and interfaces.

REFERENCE ARCHITECTURE

A small kernel. Replaceable userland.

RESEARCH PROGRAMME

Study the whole Agent OS problem.

Open Agent OS does not reduce architecture to a single framework. The research map spans runtime semantics, knowledge, security, distributed systems, interfaces, governance, and operations.

Kernel & Runtime

Resources, lifecycle, harnesses, models, orchestration, events, durability.

Knowledge & Capability

Memory, RAG, ingestion, skills, tools, MCP, browser and computer use.

Trust & Security

Identity, authorization, secrets, policy, sandboxing, red teaming, audit.

Distributed Platform

Scheduling, local AI, compute fabric, networking, data architecture, HA.

Quality & Evidence

Observability, evaluation, testing, benchmarks, provenance, failure analysis.

Developer & Organization

Plugins, API/SDK, IDEs, project lifecycle, digital workers, governance.

BUILD PATH

Start simple. Earn complexity.

Begin with a single agent, typed tools, a workspace and structured logs. Add durable state, recovery, memory, multi-agent delegation, security, and distributed compute only when the preceding layer is observable and testable.
