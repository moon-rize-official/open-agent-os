# Role-Family Resource Overlays

**Status:** INITIAL PROPOSAL

Department packs define the domain. Role-family overlays define how an agent interacts with that domain.

## Strategy / Planning

### Information
- organization goals;
- KPIs;
- constraints;
- portfolio/project state;
- risks;
- forecasts.

### Tools
- dashboards;
- spreadsheets/analysis;
- project/portfolio systems;
- research/search;
- diagramming.

### Access
Mostly read, with write access to plans/decisions.

### Outputs
- strategy;
- roadmap;
- priorities;
- decision records;
- risk plans.

---

## Analysis / Research

### Information
- primary sources;
- datasets;
- prior research;
- evidence;
- standards;
- relevant external web data.

### Tools
- search;
- browser;
- document reader;
- data analysis;
- notebooks;
- citation/provenance tools.

### Access
Read-heavy; bounded write to research artifacts/knowledge.

### Outputs
- research report;
- evidence table;
- source index;
- comparison;
- benchmark.

---

## Implementation / Delivery

### Information
- requirements;
- architecture;
- source code;
- APIs;
- schemas;
- issues;
- tests.

### Tools
- IDE/editor;
- Git;
- shell;
- compiler/build system;
- package manager;
- test runner;
- database client;
- container/dev environment.

### Access
Write to bounded project workspace; production writes require separate authority.

### Outputs
- code;
- tests;
- migrations;
- build artifacts;
- implementation notes.

### Information

### Tools
