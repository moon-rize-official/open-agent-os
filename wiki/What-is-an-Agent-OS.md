# What is an Agent OS?

There is not yet one universally accepted definition.

For this project, **Agent OS** is a working term for the platform layer that gives AI agents durable identity, execution lifecycle, capabilities, policy, state, recovery, artifacts, observability, and interoperability across replaceable implementations.

It is broader than an agent framework and narrower than “everything involving AI.”

The definition remains a research topic and should evolve as protocols and implementations mature.
