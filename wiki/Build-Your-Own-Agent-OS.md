# Build Your Own Agent OS

Recommended progression:

1. Minimal single-agent runtime
2. Canonical resource model
3. Typed capabilities and tools
4. Durable execution
5. Knowledge and memory
6. Multi-agent delegation
7. Identity, policy, sandboxing, audit
8. Distributed compute

Avoid starting with a large swarm before run state, cancellation, recovery, permissions, and observability are reliable.

Full guide: [Build Your Own Agent OS](../docs/getting-started/build-your-own-agent-os.md).
