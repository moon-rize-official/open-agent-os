# Open Agent OS Wiki

Welcome to the working Wiki for **Open Agent OS**.

Open Agent OS is a vendor-neutral knowledgebase and specification effort for modular Agent OS / AI OS architecture.

## Core idea

An Agent OS should make it possible to replace models, model providers, agent harnesses, tools, MCP servers, memory stores, knowledge systems, workflow engines, sandboxes, compute nodes, storage backends, and UI surfaces **without redesigning the entire platform**.

## Research status

The project is a research foundation, not a finalized standard. Evidence, proposals, alternatives, and open questions are kept distinct.
