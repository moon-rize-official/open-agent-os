# Glossary

**AgentDefinition** — Versioned declarative description of an agent's intended capabilities, policies, tools, and defaults.

**AgentInstance** — Runtime realization of an AgentDefinition.

**Task** — Durable unit of requested work.

**Run** — An execution attempt or execution tree associated with a task.

**Artifact** — Durable output produced or consumed by work.

**Capability** — Machine-readable declaration of something a principal, tool, model, agent, node, or environment can do.

**Harness** — Execution environment/loop that mediates between an agent definition, model, context, tools, and runtime.

**Workspace** — Filesystem/environment scope in which work occurs.

**Principal** — Authenticated identity capable of acting or receiving permissions.

**Policy** — Machine-enforceable rule governing access or behavior.
