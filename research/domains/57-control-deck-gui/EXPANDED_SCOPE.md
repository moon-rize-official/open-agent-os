# Domain 57 — Control Deck / GUI: Expanded Scope

The Control Deck should be a family of composable workspaces rather than one universal administrator screen.

Research profiles:

- personal cockpit;
- developer workspace;
- team workspace;
- organization administration;
- platform operations;
- security/compliance;
- research/knowledge;
- marketplace.

## Key research areas

- information architecture;
- role-aware navigation;
- resource inspectors;
- live run timelines;
- approval UX;
- provenance visualization;
- cost/token visualization;
- graph visualization;
- large-scale table/search UX;
- mobile/responsive surfaces;
- real-time updates;
- offline mode;
- accessibility;
- plugin slots;
- customizable dashboards;
- cross-organization switching.

## Security rule

Frontend visibility is not authorization.

All actions must still pass backend policy and identity checks.
