# Domain 59 — Marketplace / Catalog: Expanded Scope

Research catalogs and marketplaces for:

- agents;
- skills;
- MCP servers;
- plugins;
- tools;
- workflows;
- templates;
- knowledge packs;
- evaluators;
- UI components.

## Distinguish

```text
Registry    = authoritative metadata/discovery
Catalog     = organized searchable inventory
Marketplace = catalog + curation + trust + distribution + optional commerce
```

## Open Agent OS goal

Initially prioritize an open, curated compatibility catalog—not monetization.

Possible public indices:

- agents;
- skills;
- MCP servers;
- plugins;
- reference workflows;
- benchmark packs;
- UI component packs.
