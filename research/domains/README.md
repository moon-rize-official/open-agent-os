## Per-domain standard

Each domain should eventually contain:

- terminology;
- research questions;
- primary sources;
- source-code evidence;
- reference implementations;
- system comparison;
- design patterns and anti-patterns;
- failure modes;
- security analysis;
- scalability;
- interoperability;
- test/evaluation method;
- alternatives;
- recommendations;
- open questions;
- ADR/contract where appropriate.
